# Inventario de Componentes - `lib/14_geolocalizacion`

Este documento contiene el inventario técnico de los componentes definidos en cada archivo dentro del directorio **`D:\buscobien\lib\14_geolocalizacion`**.

Este módulo es el motor de geolocalización y mapas de Buscobien. Administra las llaves de acceso para las APIs de Google Maps en Android, iOS y Web, proporciona un visor interactivo de mapas capaz de renderizar marcadores personalizados (pines Canvas pintados en tiempo de ejecución con precios e iconografía adaptada a la transacción), gestiona los permisos de localización nativos y expone proveedores Riverpod que automatizan la geocodificación inversa según el sistema operativo detectado (móvil, escritorio o navegador).

## Análisis Técnico y Flujo de Geolocalización Multiplataforma

1. **Ruteo de Geolocalización Adaptativa por Sistema Operativo:**
   * El notificador `ClassLocalidadesNotifierProvider` en [provider_actual_place.dart](file:///D:/buscobien/lib/14_geolocalizacion/provider_actual_place.dart) implementa un patrón excelente para soportar múltiples plataformas:
     * **Móviles (Android / iOS):** Aprovecha la biblioteca nativa `geocoding` con `placemarkFromCoordinates()` para resolver la dirección y CP a partir de la latitud y longitud sin incurrir en costos de APIs HTTP de Google.
     * **Escritorio y Web (Windows / macOS / Web):** Debido a que la biblioteca nativa no tiene soporte estable de geocodificación en estas plataformas, rutea automáticamente el flujo hacia `getPlaceFromCoordinates()`, el cual lanza peticiones asíncronas seguras por REST contra el endpoint oficial de Google Maps Geocoding utilizando la llave `GOOGLE_MAPS_KEY`.

2. **Cocreación de Pines Interactivos Dinámicos (Canvas):**
   * En [google_map_mapa_propiedades.dart](file:///D:/buscobien/lib/14_geolocalizacion/google_map_mapa_propiedades.dart), la función `_createCustomMarkerBitmap` resuelve de forma ingeniosa el renderizado de precios sobre los mapas en lugar de utilizar marcadores genéricos. 
   * Dibuja de manera digital y en tiempo de ejecución (`ui.PictureRecorder`) un globo redondeado, una flecha de apuntamiento, define colores contrastantes basados en el tipo de transacción (p.ej. Azul de `appTheme.primary` para Venta, Naranja/Verde para Renta/Otros) y escribe el precio del inmueble usando `TextPainter`. Finalmente, genera un PNG en memoria y lo inyecta como un `BitmapDescriptor.bytes` para un despliegue ultra veloz y premium.

3. **Arquitectura de Sincronización de Códigos Postales:**
   * Tanto el flujo nativo como el REST de Geocodificación inversa resuelven el código postal. Al identificarlo, ambos ejecutan de manera inmediata la propagación:
     ```dart
     ref.read(localidadesPorCodigoPostalProvider.notifier).setCodigoPostal(cp);
     ```
     Esto causa que los menús desplegables de búsqueda en la pantalla principal carguen al instante los asentamientos del código postal detectado en tiempo real sin que el usuario tenga que capturarlo de forma manual.
