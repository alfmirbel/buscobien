## Notas

- Las User Stories dedicadas (`main.md`, `01_splash_screen.md`, `01_home.md`, `07_routes.md`) usan formato 3 C's completo (Card, Conversation, Confirmation) por separado.
- Los subsistemas menores consolidados en `03_listas.md` usan formato 3 C's compacto (Card + Confirmation, sin Conversation exhaustiva por brevedad — ver Features BDD e Inventarios para detalle técnico de cada subsistema).
- Total User Stories creadas en Lotes B+C: **33 stories** cubriendo 17 subsistemas.
